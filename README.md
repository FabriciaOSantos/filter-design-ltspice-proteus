# Filter Design with LTspice, Proteus and Arduino

Academic project focused on analog and digital filter design, simulation and implementation support.

## Overview

- Low-pass filter design
- Band-pass filter design
- Transfer function analysis
- Bode and root-locus analysis
- LTspice circuit simulation
- Proteus project with Arduino code for a digital low-pass filter

## Tools

- LTspice
- Proteus
- Arduino
- MATLAB
- Texas Instruments Filter Design Tool

## Repository structure

- `docs/`: project report
- `simulation/ltspice/`: LTspice filter schematics
- `simulation/proteus/`: Proteus simulation project
- `src/arduino/`: Arduino source code

## Files

- `docs/filter-design-report.pdf`: project report
- `simulation/ltspice/low_pass_filter.asc`: low-pass filter LTspice schematic
- `simulation/ltspice/band_pass_filter.asc`: band-pass filter LTspice schematic
- `simulation/proteus/low_pass_digital_filter.pdsprj`: Proteus project
- `src/arduino/low_pass_filter_arduino.ino`: Arduino code

## Topics

- Analog filters
- Digital filters
- Chebyshev filter design
- Frequency response
- Circuit simulation
